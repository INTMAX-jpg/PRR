# Third-party assets

External benchmarks and model checkpoints are obtained from their original providers. Repository-specific terms apply independently of the author team's code/data license decision.

| Asset | Provider | Provider-card license |
|---|---|---|
| MMLU | https://huggingface.co/datasets/cais/mmlu | MIT |
| ARC-Challenge | https://huggingface.co/datasets/allenai/ai2_arc | CC BY-SA 4.0 |
| GSM8K | https://huggingface.co/datasets/openai/gsm8k | MIT |
| Qwen3-1.7B | https://huggingface.co/Qwen/Qwen3-1.7B | Apache-2.0 |

The dataset/model cards above were checked on 2026-11-04. Other model identifiers appear in the portable configurations; consult each provider's model card and accept its terms when acquiring a checkpoint. Examples include the Meta Llama 3 Community License and Gemma terms. Save the exact resolved repository revision with each run.

Readout parameters in this repository are the fitted diagnostic models for the supplied experiments. The external language-model checkpoints are acquired separately through their providers. Times New Roman must be available from the user's licensed font installation.
